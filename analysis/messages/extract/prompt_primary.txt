You read messages from a cooperative grid game and list every statement of where an object is now. A program checks each item against the game log, so your job is only to find and copy such statements. You never judge whether they are true.

THE GAME
Players move lettered objects, capital letters A to F, on a square grid, one cell per turn. Rows are R1, R2 and so on from the top, columns C1, C2 and so on from the left, and a cell is written (Rr,Cc), so (R3,C5) is row 3, column 5. On its own board a player sees its teammates' objects only as X. Each message below says which objects belong to its writer.

WHAT TO LIST
A statement, given as a fact, that an object that is not the writer's own is on a cell at the time of writing. For example "E is at (R2,C6)", "D sits on R4C1", "(R3,C3) is occupied by B" and "C just moved to (R5,C2)" each say where that object is now.

Leave out
- destinations, targets and goals ("moving D to (R2,C3)", "B's goal is (R1,C1)")
- plans and future positions ("E will be at (R2,C6)", "next turn C reaches (R4,C4)")
- requests and orders ("B, wait at (R2,C3)", "keep F at (R5,C5)", "please move D from (R3,C3)")
- conditions ("if E is at (R2,C6) I go left")
- questions ("is E at (R2,C6)?")
- what someone else said ("Blue says E is at (R2,C6)")
- negations ("E is not at (R2,C6)")
- statements about the writer's own objects

COPYING
- The letter and the cell must both be written in the span. Never turn "your object", "it", "that cell" or "the X near the corridor" into a letter or a cell.
- Copy the span character for character from the message, as short as you can, one clause where possible.
- Write the cell as (Rr,Cc). A cell written R3C4, R3,C4 or (R3, C4) in the message becomes (R3,C4).

ANSWER
One JSON array for the whole batch and nothing else. Each item is [message number, "letter", "(Rr,Cc)", "span"]. Answer [] when no message has such a statement.
Example
[[1, "E", "(R2,C6)", "E is at (R2,C6)"], [3, "B", "(R3,C3)", "(R3,C3) is occupied by B"]]
=== INPUT ===
<<MESSAGES>>
