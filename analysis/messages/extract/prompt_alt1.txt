Below is a batch of messages that players sent each other in a cooperative grid game. Find each place where a writer tells the others the current cell of an object that belongs to someone else. A program later compares what you find with the game log, so do not decide whether a statement is correct, only find and copy it.

ABOUT THE GAME
The objects are the capital letters A to F. They sit on a square grid and move one cell per turn. R1 is the top row and C1 the leftmost column, and a cell is written (Rr,Cc), for instance (R3,C5) for row 3, column 5. A player's own board shows other players' objects as X only. The header of each message names the writer's own objects.

WHAT COUNTS
The writer says, as a plain fact, that another player's object occupies a cell right now. Examples that count are "(R3,C3) is occupied by B", "C just moved to (R5,C2)", "D sits on R4C1" and "E is at (R2,C6)".

What does not count
- statements about the writer's own objects
- claims attributed to another player ("Blue says E is at (R2,C6)")
- denials ("E is not at (R2,C6)")
- questions ("is E at (R2,C6)?")
- conditions ("if E is at (R2,C6) I go left")
- instructions and requests ("please move D from (R3,C3)", "keep F at (R5,C5)", "B, wait at (R2,C3)")
- future positions and plans ("next turn C reaches (R4,C4)", "E will be at (R2,C6)")
- goals, targets and destinations ("B's goal is (R1,C1)", "moving D to (R2,C3)")

HOW TO COPY
- The span must contain both the letter and the cell. Do not convert "it", "your object", "that cell" or "the X near the corridor" into a letter or a cell.
- Copy the span exactly as written in the message, keep it short, ideally a single clause.
- Give the cell as (Rr,Cc), so R3C4, R3,C4 or (R3, C4) in the message is given as (R3,C4).

ANSWER
One JSON array for the whole batch and nothing else. Each item is [message number, "letter", "(Rr,Cc)", "span"]. Answer [] when no message has such a statement.
Example
[[1, "E", "(R2,C6)", "E is at (R2,C6)"], [3, "B", "(R3,C3)", "(R3,C3) is occupied by B"]]
=== INPUT ===
<<MESSAGES>>
