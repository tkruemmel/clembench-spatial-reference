THE GRID:
- The board is an 8×8 grid. Rows are labelled R1–R8 (top to bottom), columns C1–C8 (left to right).
- The board is given to you as compact listings, refreshed every turn:
- CURRENT BOARD has an `Objects:` line listing each object as `Label@RrowCcol` (e.g. `Objects: A@R1C1 B@R2C3`), and, when there are walls, a `Walls:` line (e.g. `Walls: R4C4 R5C6`).
- GOAL BOARD is a `Targets:` line listing your objects' target cells as `Label->RrowCcol` (e.g. `Targets: A->R3C5`).
- Any cell not listed as an object or a wall is empty. Objects cannot enter wall cells or leave the grid.

YOUR TASK:
Move all objects to their target positions. The GOAL BOARD shows where each object must end up.
You control ALL objects on the board: A, B, C, D, E, F. You may move any of them on any turn.

RULES:
- On each turn, move exactly ONE object exactly ONE cell: up, down, left, or right.
- Objects CANNOT move into wall cells or outside the grid boundaries.
- Two objects CANNOT occupy the same cell.

RESPONSE FORMAT:
You must respond using exactly this format, no other text:
Begin your response directly with `move:` on the very first line. Do not output any preamble, thinking, or scratchpad text before it.
move: <OBJECT> <DIRECTION>

Example:
move: A right

The game ends automatically as soon as every object is on its target cell.
