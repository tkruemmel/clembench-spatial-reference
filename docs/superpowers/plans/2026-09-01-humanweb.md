# Human Web Play (`humanweb`) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let humans play the covered matrix games (solo, dyad, 3p, 6p) in a browser, producing episode data byte-identical in structure to model episodes.

**Architecture:** A human becomes a clemcore *backend*. `humanweb_api.py` at the repo root defines a `Backend`/`Model` pair whose `generate_response()` parks the turn context on a small FastAPI service and polls until the participant submits. The game master, board, validator and scorers are never touched, so `clem score` and every existing analysis script work unchanged. A console picks which episodes to play and spawns one `clem run` subprocess per block.

**Tech Stack:** Python 3.12, clemcore 3.7.2, FastAPI 0.136 + uvicorn 0.47 (already installed), httpx, pytest. Vanilla HTML/JS for the UI — no build step, no framework.

**Spec:** `docs/superpowers/specs/2026-09-01-human-matrixgame-web-design.md`

## Global Constraints

- **No existing machinery may be modified.** No edits under `matrixgame_covered_solo/`, `matrixgame_covered_comm/`, `matrixgame_covered_comm_nplayer/`, `matrixgame_covered_shared/`, `campaign/`, or `clemcore`. The only pre-existing file this plan touches is `model_registry.json`, and only to append one entry.
- **The turn budget is untouched.** Never write or override `max_turns`. Human episodes run the canonical instance files.
- **Every seat registers under the model name `human-text`.** Per-participant model names would fragment the results tree (`Model.to_identifier`, `clemcore/backends/model_registry.py:421`).
- **Participant text is returned verbatim.** The only permitted transformation is CRLF → LF normalisation, applied once in the submit endpoint and covered by a test.
- **Polling everywhere, 1-second interval.** No websockets, no SSE, no long-poll timeout tuning.
- **Commit messages must not contain a `Co-Authored-By: Claude` trailer** (repo convention).
- Python: 4-space indent, type hints on public functions, module docstring on every new module — match the style of `matrixgame_covered_solo/master.py`.

## File Structure

| File | Responsibility |
|---|---|
| `humanweb_api.py` (repo root) | `HumanWebBackend` + `HumanWebModel` + `SeatAbandoned`. Seat allocation and the blocking turn call. Nothing else. |
| `humanweb/__init__.py` | Empty package marker. |
| `humanweb/state.py` | `SeatState`, `SessionStore` — in-memory seat state behind a lock. No HTTP. |
| `humanweb/service.py` | FastAPI app: internal turn-exchange endpoints, participant endpoints, page serving. |
| `humanweb/selection.py` | Pure functions: resume predicate, level interleaving, Latin-square seat rotation, per-turn estimate, stop-time guard. No I/O beyond reading the results tree. |
| `humanweb/console.py` | CLI: shows outstanding episodes, writes the filtered instance file, spawns/kills `clem run`, prints seat links. |
| `humanweb/join.py` | Joins `turns.jsonl` + `manifest.json` against the results tree into one analysis table. |
| `humanweb/web/play.html` | The single play page. Inline CSS/JS, no assets. |
| `humanweb/tests/*.py` | pytest suite. `__init__.py` + `conftest.py` follow the repo convention (`matrixgame_covered_solo/tests/conftest.py`): an explicit `sys.path.insert` rather than a pytest config file. |

The spec's `humanweb/lobby` unit is **not** a separate module here. `LabLobby`
is "named seats, no gate", which is one `--seats` argument; splitting it out
before `ProlificLobby` exists would be an abstraction with one implementation.
It gets extracted when the Prolific plan needs it.

Task order builds strictly bottom-up: state → service → backend → identity proof → UI → selection → console → join.

```python
"""Human-in-the-browser backend for clembench.

A human participant is exposed to clemcore as an ordinary `Model`. Each seat in
an episode gets its own `HumanWebModel`; `generate_response` parks the turn
context on the humanweb service and polls until the participant submits.

Seat ids are handed out from module-level state, because clemcore constructs a
fresh Backend for every `-m` selector (clemcore/backends/__init__.py:83-90), so
instance state would restart the count on every seat.

Mirrors clemcore/backends/slurk_api.py, whose SlurkModel blocks the same way.
"""

import logging
import os
import time
from typing import Any, Dict, List, Optional, Tuple

import httpx

from clemcore import backends
from clemcore.backends import Model, ModelSpec
from clemcore.backends.utils import augment_response_object, ensure_messages_format

logger = logging.getLogger(__name__)

NAME = "humanweb"

POLL_INTERVAL_SECONDS = 1.0

_seat_counter = 0


def reset_seat_counter() -> None:
    """Restart seat allocation. Used by tests and between episodes in-process."""
    global _seat_counter
    _seat_counter = 0


def _next_seat_id() -> int:
    global _seat_counter
    seat_id = _seat_counter
    _seat_counter += 1
    return seat_id


class SeatAbandoned(Exception):
    """Raised when a seat is abandoned (stop-for-the-day, or participant gone).

    Propagates out of generate_response so that the per-instance handler in
    clemcore/clemgame/runners/sequential.py:42 ends this episode and moves on.
    Because on_game_end never fires, no interactions.json is written and the
    episode is replayed on a later afternoon.
    """


class HumanWebBackend(backends.Backend):
    """Factory handing each `-m humanweb` selector its own seat."""

    def get_model_for(self, model_spec: ModelSpec) -> "HumanWebModel":
        service_url = os.environ.get("HUMANWEB_SERVICE_URL")
        session_id = os.environ.get("HUMANWEB_SESSION_ID")
        if not service_url:
            raise ValueError("HUMANWEB_SERVICE_URL is not set in the environment")
        if not session_id:
            raise ValueError("HUMANWEB_SESSION_ID is not set in the environment")
        return HumanWebModel(
            model_spec=model_spec,
            seat_id=_next_seat_id(),
            session_id=session_id,
            service_url=service_url.rstrip("/"),
        )


class HumanWebModel(Model):
    """One seat at one episode, backed by a participant in a browser."""

    def __init__(self, model_spec: ModelSpec, seat_id: int, session_id: str, service_url: str):
        super().__init__(model_spec)
        self.set_gen_args(temperature=0.0)  # dummy, for get_temperature()
        self.seat_id = seat_id
        self.session_id = session_id
        self.service_url = service_url

    @augment_response_object
    @ensure_messages_format
    def generate_response(self, messages: List[Dict]) -> Tuple[Any, Any, str]:
        raise NotImplementedError("wired up in Task 3")
```

```python
"""In-memory seat state for the humanweb turn exchange.

One process serves one afternoon, so a dict behind a lock is sufficient; there
is deliberately no database. State is per (session, seat) and is cleared at
episode boundaries.
"""

import threading
import time
from dataclasses import dataclass, field
from typing import Dict, Optional, Tuple


@dataclass
class SeatState:
    """What one seat is currently waiting on."""
    pinned: Optional[str] = None
    context: Optional[str] = None
    turn_id: int = 0
    response: Optional[str] = None
    response_turn_id: Optional[int] = None
    abandoned: bool = False
    parked_at: Optional[float] = None
    submitted_at: Optional[float] = None


class SessionStore:
    """Thread-safe map of (session, seat) -> SeatState."""

    def __init__(self) -> None:
        self._lock = threading.Lock()
        self._seats: Dict[Tuple[str, int], SeatState] = {}

    def _seat(self, session: str, seat: int) -> SeatState:
        return self._seats.setdefault((session, seat), SeatState())

    def park(self, session: str, seat: int, pinned: Optional[str], context: str) -> int:
        """Publish a new turn context for a seat. Returns the new turn id."""
        with self._lock:
            state = self._seat(session, seat)
            state.turn_id += 1
            state.pinned = pinned
            state.context = context
            state.response = None
            state.response_turn_id = None
            state.parked_at = time.time()
            state.submitted_at = None
            return state.turn_id

    def submit(self, session: str, seat: int, turn_id: int, text: str) -> str:
        """Record a participant submission. Returns 'ok', 'stale' or 'duplicate'."""
        with self._lock:
            state = self._seat(session, seat)
            if turn_id != state.turn_id:
                return "stale"
            if state.response is not None:
                return "duplicate"
            state.response = text
            state.response_turn_id = turn_id
            state.submitted_at = time.time()
            return "ok"

    def take_response(self, session: str, seat: int) -> Tuple[Optional[str], Optional[str]]:
        """Return (text, None) once submitted, else (None, 'pending'|'abandoned')."""
        with self._lock:
            state = self._seat(session, seat)
            if state.abandoned:
                return None, "abandoned"
            if state.response is None:
                return None, "pending"
            return state.response, None

    def abandon(self, session: str, seat: int) -> None:
        with self._lock:
            self._seat(session, seat).abandoned = True

    def end_episode(self, session: str) -> None:
        """Clear every seat of a session between episodes."""
        with self._lock:
            for (sess, seat) in list(self._seats):
                if sess == session:
                    self._seats[(sess, seat)] = SeatState()

    def view(self, session: str, seat: int) -> Dict:
        """Everything the play page needs, including whose turn it is."""
        with self._lock:
            state = self._seat(session, seat)
            active = None
            for (sess, other_seat), other in self._seats.items():
                if sess == session and other.context is not None and other.response is None:
                    if active is None or other_seat < active:
                        active = other_seat
            return {
                "seat": seat,
                "turn_id": state.turn_id,
                "pinned": state.pinned,
                "context": state.context,
                "your_turn": state.context is not None and state.response is None,
                "active_seat": active,
                "abandoned": state.abandoned,
            }
```

```python
"""FastAPI turn exchange between blocked `clem run` seats and browsers.

Endpoints split in two: `/internal/*` is spoken by humanweb_api.py inside the
clem subprocess, `/api/*` and `/play/*` by the participant's browser. Both sides
poll on a one-second interval; there are deliberately no websockets.
"""

from pathlib import Path
from typing import Optional

from fastapi import FastAPI, HTTPException
from fastapi.responses import HTMLResponse
from pydantic import BaseModel

from humanweb.state import SessionStore

WEB_DIR = Path(__file__).parent / "web"


class ParkRequest(BaseModel):
    session: str
    seat: int
    pinned: Optional[str] = None
    context: str


class SubmitRequest(BaseModel):
    turn_id: int
    text: str


def create_app(store: SessionStore) -> FastAPI:
    app = FastAPI(title="humanweb")

    @app.post("/internal/turn")
    def park_turn(req: ParkRequest):
        turn_id = store.park(req.session, req.seat, req.pinned, req.context)
        return {"turn_id": turn_id}

    @app.get("/internal/turn/{session}/{seat}")
    def poll_turn(session: str, seat: int):
        text, status = store.take_response(session, seat)
        if status is not None:
            return {"status": status, "response": None}
        return {"status": "ready", "response": text}

    @app.post("/internal/episode/{session}/end")
    def end_episode(session: str):
        store.end_episode(session)
        return {"status": "cleared"}

    @app.get("/api/state/{session}/{seat}")
    def get_state(session: str, seat: int):
        return store.view(session, seat)

    @app.post("/api/submit/{session}/{seat}")
    def submit(session: str, seat: int, req: SubmitRequest):
        # CRLF -> LF is the ONLY transformation applied to participant text.
        text = req.text.replace("\r\n", "\n")
        result = store.submit(session, seat, req.turn_id, text)
        if result != "ok":
            raise HTTPException(status_code=409, detail=result)
        return {"status": "ok"}

    @app.post("/api/abandon/{session}/{seat}")
    def abandon(session: str, seat: int):
        store.abandon(session, seat)
        return {"status": "abandoned"}

    @app.get("/play/{session}/{seat}", response_class=HTMLResponse)
    def play(session: str, seat: int):
        return (WEB_DIR / "play.html").read_text(encoding="utf-8")

    return app
```

```python
    @ensure_messages_format
    def generate_response(self, messages: List[Dict]) -> Tuple[Any, Any, str]:
        """Park this turn's context, then poll until the participant submits.

        `messages` is [pinned preamble, current context] for Markovian players
        (clemcore/clemgame/player.py:134). Only the last message changes per
        turn; the preamble is shown once in the page's rules panel.
        """
        pinned = messages[0]["content"] if len(messages) > 1 else None
        context = messages[-1]["content"]

        httpx.post(
            f"{self.service_url}/internal/turn",
            json={"session": self.session_id, "seat": self.seat_id,
                  "pinned": pinned, "context": context},
            timeout=30.0,
        ).raise_for_status()

        poll_url = f"{self.service_url}/internal/turn/{self.session_id}/{self.seat_id}"
        while True:
            payload = httpx.get(poll_url, timeout=30.0).json()
            status = payload["status"]
            if status == "ready":
                return messages, {"response": "humanweb"}, payload["response"]
            if status == "abandoned":
                raise SeatAbandoned(
                    f"seat {self.seat_id} of session {self.session_id} was abandoned")
            time.sleep(POLL_INTERVAL_SECONDS)

    def reset(self) -> None:

        httpx.post(
            f"{self.service_url}/internal/episode/{self.session_id}/end", timeout=30.0)
```

```python
Everything except timestamps and the model name is produced by untouched game
code, so any difference here means the backend is altering the game.
"""

import json
import os
import shutil
import subprocess
import threading
import time
from pathlib import Path

import httpx
import pytest

REPO_ROOT = Path(__file__).resolve().parents[2]
FIXTURE = Path(__file__).parent / "fixtures" / "instances_identity.json"
INSTANCES_NAME = "instances_humanweb_identity"
GAME_DIR = REPO_ROOT / "matrixgame_covered_solo" / "in"
EXPERIMENT = "Identity_S1_Silent_Compact"

VOLATILE_KEYS = {"timestamp", "model_name", "results_folder", "clem_version"}


def _mask(node):
    """Recursively drop keys that legitimately differ between two runs."""
    if isinstance(node, dict):
        return {k: _mask(v) for k, v in node.items() if k not in VOLATILE_KEYS}
    if isinstance(node, list):
        return [_mask(v) for v in node]
    return node


def _only_interactions(results_dir: Path) -> dict:
    found = list(results_dir.rglob("interactions.json"))
    assert len(found) == 1, f"expected exactly one episode, found {len(found)}"
    return json.loads(found[0].read_text())

    """Place the fixture where `clem run -i` will find it, then remove it."""
    target = GAME_DIR / f"{INSTANCES_NAME}.json"

    yield INSTANCES_NAME
    target.unlink(missing_ok=True)


def _run_clem(model: str, results_dir: Path, instances: str, env_extra=None) -> None:
    env = {**os.environ, **(env_extra or {})}
    proc = subprocess.run(
        ["clem", "run", "-g", "matrixgame_covered_solo", "-m", model,
         "-i", instances, "-r", str(results_dir), "-e", EXPERIMENT],
        cwd=REPO_ROOT, env=env, capture_output=True, text=True, timeout=300)
    assert proc.returncode == 0, proc.stderr[-3000:]


def _drive_seat(base_url: str, session: str, stop: threading.Event) -> None:
    """Post the same move the programmatic player would, every turn."""
    seen = 0
    while not stop.is_set():
        try:
            state = httpx.get(f"{base_url}/api/state/{session}/0", timeout=5).json()
        except httpx.TransportError:
            time.sleep(0.2)
            continue
        if state["your_turn"] and state["turn_id"] != seen:
            seen = state["turn_id"]
            httpx.post(f"{base_url}/api/submit/{session}/0",
                       json={"turn_id": seen, "text": "move: A down"}, timeout=5)
        time.sleep(0.2)

    human_dir = tmp_path / "human"
    stop = threading.Event()
    driver = threading.Thread(
        target=_drive_seat, args=(base_url, "identity", stop), daemon=True)
    driver.start()

            "HUMANWEB_SERVICE_URL": base_url, "HUMANWEB_SESSION_ID": "identity"})
    finally:

        driver.join(timeout=5)

    assert _mask(_only_interactions(human_dir)) == _mask(_only_interactions(programmatic_dir))
```

```python
"""Deciding what to play next, and who sits where.

Pure functions plus reads of the results tree. The resume signal is the same one
campaign/remaining.py uses: an episode counts as finished iff its
interactions.json exists.

Deviation from campaign/remaining.py, on purpose: episodes are interleaved
across spatial levels rather than sorted S1 -> S4. Over many afternoons a
level-sorted order would confound spatial level with participant expertise.
"""

import json
import statistics
from dataclasses import dataclass
from pathlib import Path
from typing import Dict, List

DEFAULT_SECONDS_PER_TURN = 25.0
LEVEL_ORDER = ("S1", "S2", "S3", "S4")


@dataclass(frozen=True)
class Episode:
    experiment: str
    game_id: int
    level: str
    max_turns: int
    instance: Dict


def load_episodes(instances_path: Path) -> List[Episode]:
    data = json.loads(Path(instances_path).read_text())
    episodes: List[Episode] = []
    for experiment in data["experiments"]:
        for instance in experiment["game_instances"]:
            episodes.append(Episode(
                experiment=experiment["name"],
                game_id=instance["game_id"],
                level=instance.get("spatial_level", "S9"),
                max_turns=instance["max_turns"],
                instance=instance,
            ))
    return episodes


def is_done(results_root: Path, run_dir: str, game_name: str, episode: Episode) -> bool:
    path = (Path(results_root) / run_dir / game_name / episode.experiment
            / f"instance_{episode.game_id:05d}" / "interactions.json")
    return path.exists()


def outstanding(episodes: List[Episode], results_root: Path, run_dir: str,
                game_name: str) -> List[Episode]:
    return [e for e in episodes if not is_done(results_root, run_dir, game_name, e)]


def interleave_levels(episodes: List[Episode]) -> List[Episode]:
    """Round-robin across spatial levels so practice spreads evenly."""
    buckets: Dict[str, List[Episode]] = {}
    for episode in episodes:
        buckets.setdefault(episode.level, []).append(episode)
    ordered_levels = [lvl for lvl in LEVEL_ORDER if lvl in buckets]
    ordered_levels += sorted(lvl for lvl in buckets if lvl not in LEVEL_ORDER)

    result: List[Episode] = []
    while any(buckets[lvl] for lvl in ordered_levels):
        for level in ordered_levels:
            if buckets[level]:
                result.append(buckets[level].pop(0))
    return result


def seat_for(participant_index: int, afternoon_index: int, n_seats: int) -> int:
    """Cyclic Latin square: every participant visits every seat over n afternoons."""
    return (participant_index + afternoon_index) % n_seats


def parse_duration(text: str) -> float:
    """Parse a `str(timedelta)` value such as '0:00:17.412000' into seconds."""
    hours, minutes, seconds = text.split(":")
    return int(hours) * 3600 + int(minutes) * 60 + float(seconds)


def estimate_seconds_per_turn(results_root: Path,
                              default: float = DEFAULT_SECONDS_PER_TURN) -> float:
    """Median observed human turn duration, from recorded clem_player metadata."""
    durations: List[float] = []
    for requests_file in Path(results_root).rglob("player_*.requests.json"):
        try:
            payload = json.loads(requests_file.read_text())
        except (json.JSONDecodeError, OSError):
            continue
        for call in payload.get("calls", []):
            metadata = call.get("call", {}).get("raw_response_obj", {}).get("clem_player")
            if metadata and "call_duration" in metadata:
                durations.append(parse_duration(metadata["call_duration"]))
    return statistics.median(durations) if durations else default


def fits_before_stop(episode: Episode, seconds_per_turn: float,
                     now: float, stop_at: float) -> bool:
    """True when the episode's worst case finishes before the declared stop time."""
    return now + episode.max_turns * seconds_per_turn <= stop_at


def write_filtered_instances(src: Path, dest: Path, episodes: List[Episode]) -> None:
    """Write a filtered copy holding only `episodes`, instances copied unchanged.

    The canonical instances file is never modified, matching the convention in
    campaign/remaining.py. Instance dicts are copied verbatim; in particular
    max_turns is never rewritten.
    """
    data = json.loads(Path(src).read_text())
    wanted = {(e.experiment, e.game_id) for e in episodes}
    experiments = []
    for experiment in data["experiments"]:
        kept = [g for g in experiment["game_instances"]
                if (experiment["name"], g["game_id"]) in wanted]
        if kept:
            experiments.append({**experiment, "game_instances": kept})
    Path(dest).write_text(json.dumps({**data, "experiments": experiments}, indent=2))
```

```python
"""Experimenter console: pick episodes, serve seats, run one block.

A block is a group of episodes played back to back by one `clem run`
subprocess. Stopping for the day is a SIGTERM: the in-flight episode writes no
interactions.json and is replayed on a later afternoon.
"""

import argparse
import json
import os
import signal
import subprocess
import sys
import threading
import time
from dataclasses import dataclass
from pathlib import Path
from typing import List, Optional

import uvicorn

from humanweb.selection import (
    Episode, estimate_seconds_per_turn, fits_before_stop, interleave_levels,
    load_episodes, outstanding, write_filtered_instances,
)
from humanweb.service import create_app
from humanweb.state import SessionStore

REPO_ROOT = Path(__file__).resolve().parents[1]
MODEL_NAME = "human-text"


@dataclass(frozen=True)
class SuiteConfig:
    game_name: str
    game_dir: str
    instances: str
    n_seats: int


SUITES = {
    "solo": SuiteConfig("matrixgame_covered_solo", "matrixgame_covered_solo",
                        "instances", 1),
    "dyad": SuiteConfig("matrixgame_covered_comm", "matrixgame_covered_comm",
                        "instances", 2),
    "3p": SuiteConfig("matrixgame_covered_comm_3p", "matrixgame_covered_comm_nplayer",
                      "instances_3p", 3),
    "6p": SuiteConfig("matrixgame_covered_comm_6p", "matrixgame_covered_comm_nplayer",
                      "instances_6p", 6),
}


def run_dir_for(n_seats: int) -> str:
    """The results run directory clemcore will choose for n identical seats."""
    from clemcore.backends import ModelSpec
    from clemcore.backends.model_registry import Model

    class _Named(Model):
        def generate_response(self, messages):  # pragma: no cover - never called
            raise NotImplementedError

    models = [_Named(ModelSpec(model_name=MODEL_NAME)) for _ in range(n_seats)]
    return Model.to_identifier(models)


def plan_block(suite: SuiteConfig, results_root: Path, seconds_per_turn: float,
               now: float, stop_at: float, limit: int) -> List[Episode]:
    """Outstanding episodes, level-interleaved, that fit before the stop time."""
    instances_path = REPO_ROOT / suite.game_dir / "in" / f"{suite.instances}.json"
    episodes = load_episodes(instances_path)
    todo = outstanding(episodes, results_root, run_dir_for(suite.n_seats), suite.game_name)
    ordered = interleave_levels(todo)
    planned: List[Episode] = []
    for episode in ordered:
        if len(planned) >= limit:
            break
        if fits_before_stop(episode, seconds_per_turn, now, stop_at):
            planned.append(episode)
    return planned


def seat_links(base_url: str, session_id: str, n_seats: int) -> List[str]:
    return [f"{base_url.rstrip('/')}/play/{session_id}/{seat}" for seat in range(n_seats)]


def _serve(store: SessionStore, host: str, port: int) -> uvicorn.Server:
    config = uvicorn.Config(create_app(store), host=host, port=port, log_level="warning")
    server = uvicorn.Server(config)
    threading.Thread(target=server.run, daemon=True).start()
    time.sleep(1.0)
    return server


def _spawn_run(suite: SuiteConfig, instances_stem: str, results_root: Path,
               session_id: str, base_url: str) -> subprocess.Popen:
    env = {**os.environ,
           "HUMANWEB_SERVICE_URL": base_url,
           "HUMANWEB_SESSION_ID": session_id}
    command = ["clem", "run", "-g", suite.game_name,
               "-m", *([MODEL_NAME] * suite.n_seats),
               "-i", instances_stem, "-r", str(results_root)]
    print("  $ " + " ".join(command))
    return subprocess.Popen(command, cwd=REPO_ROOT, env=env)


def main(argv: Optional[List[str]] = None) -> int:
    parser = argparse.ArgumentParser(description="Run one humanweb block.")
    parser.add_argument("suite", choices=sorted(SUITES))
    parser.add_argument("--results", default="results_human")
    parser.add_argument("--session", required=True, help="session id, e.g. aft03")
    parser.add_argument("--stop-in-minutes", type=float, required=True)
    parser.add_argument("--limit", type=int, default=8)
    parser.add_argument("--host", default="0.0.0.0")
    parser.add_argument("--port", type=int, default=8765)
    parser.add_argument("--public-host", default=None,
                        help="hostname participants use; defaults to --host")
    parser.add_argument("--dry-run", action="store_true")
    args = parser.parse_args(argv)

    suite = SUITES[args.suite]
    results_root = REPO_ROOT / args.results
    seconds_per_turn = estimate_seconds_per_turn(results_root)
    stop_at = time.time() + args.stop_in_minutes * 60

    planned = plan_block(suite, results_root, seconds_per_turn,
                         now=time.time(), stop_at=stop_at, limit=args.limit)

    print(f"suite={args.suite} seats={suite.n_seats} "
          f"run_dir={run_dir_for(suite.n_seats)}")
    print(f"estimated {seconds_per_turn:.1f}s/turn; "
          f"stop in {args.stop_in_minutes:.0f} min")
    if not planned:
        print("Nothing fits before the stop time (or the suite is complete).")
        return 1
    for episode in planned:
        minutes = episode.max_turns * seconds_per_turn / 60
        print(f"  {episode.level} {episode.experiment} "
              f"instance_{episode.game_id:05d}  worst case {minutes:.0f} min")
    if args.dry_run:
        return 0

    instances_stem = f"instances_human_{args.suite}_{args.session}"
    write_filtered_instances(
        REPO_ROOT / suite.game_dir / "in" / f"{suite.instances}.json",
        REPO_ROOT / suite.game_dir / "in" / f"{instances_stem}.json",
        planned)

    store = SessionStore()
    server = _serve(store, args.host, args.port)
    public = args.public_host or args.host
    base_url = f"http://{public}:{args.port}"
    print("\nSeat links:")
    for seat, link in enumerate(seat_links(base_url, args.session, suite.n_seats)):
        print(f"  seat {seat}: {link}")

    process = _spawn_run(suite, instances_stem, results_root, args.session,
                         f"http://127.0.0.1:{args.port}")
    print("\nCtrl-C to stop for the day "
          "(the in-flight episode is discarded and replayed later).\n")
    try:
        process.wait()
    except KeyboardInterrupt:
        print("\nStopping — abandoning seats so the run exits cleanly.")
        for seat in range(suite.n_seats):
            store.abandon(args.session, seat)
        try:
            process.wait(timeout=60)
        except subprocess.TimeoutExpired:
            process.send_signal(signal.SIGTERM)
            process.wait(timeout=30)
    finally:
        server.should_exit = True
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

```python
"""Join session bookkeeping to the results tree.

The service never writes into an episode directory while a run is in flight; it
appends to turns.jsonl instead. This module performs the join afterwards, so a
SIGTERM mid-episode cannot corrupt anything.
"""

import argparse
import csv
import json
import statistics
import sys
from pathlib import Path
from typing import Dict, List, Optional

from humanweb.selection import parse_duration

SESSIONS_DIRNAME = "_sessions"


def write_manifest(path: Path, session_id: str, suite: str,
                   seats: Dict[int, str], afternoon_index: int) -> None:
    """Record which participant sat in which seat for one session."""
    Path(path).parent.mkdir(parents=True, exist_ok=True)
    Path(path).write_text(json.dumps({
        "session_id": session_id,
        "suite": suite,
        "afternoon_index": afternoon_index,
        "seats": {str(seat): participant for seat, participant in seats.items()},
    }, indent=2))


def _median_turn_seconds(episode_dir: Path) -> Optional[float]:
    durations: List[float] = []
    for requests_file in sorted(episode_dir.glob("player_*.requests.json")):
        payload = json.loads(requests_file.read_text())
        for call in payload.get("calls", []):
            metadata = call.get("call", {}).get("raw_response_obj", {}).get("clem_player")
            if metadata and "call_duration" in metadata:
                durations.append(parse_duration(metadata["call_duration"]))
    return statistics.median(durations) if durations else None


def build_table(results_root: Path, sessions_root: Path) -> List[Dict]:
    """One row per scored human episode, with instance facts and latency."""
    results_root, sessions_root = Path(results_root), Path(sessions_root)
    rows: List[Dict] = []
    for interactions_file in sorted(results_root.rglob("interactions.json")):
        if sessions_root in interactions_file.parents:
            continue
        episode_dir = interactions_file.parent
        scores_file = episode_dir / "scores.json"
        instance_file = episode_dir / "instance.json"
        if not scores_file.exists() or not instance_file.exists():
            continue
        interactions = json.loads(interactions_file.read_text())
        scores = json.loads(scores_file.read_text())["episode scores"]
        instance = json.loads(instance_file.read_text())
        meta = interactions.get("meta", {})
        rows.append({
            "run_dir": episode_dir.relative_to(results_root).parts[0],
            "game_name": meta.get("game_name"),
            "experiment": meta.get("experiment_name"),
            "game_id": meta.get("game_id"),
            "spatial_level": instance.get("spatial_level"),
            "max_turns": instance.get("max_turns"),
            "success": scores.get("Success"),
            "aborted": scores.get("Aborted"),
            "lose": scores.get("Lose"),
            "main_score": scores.get("Main Score"),
            "move_count": scores.get("Move Count"),
            "median_turn_seconds": _median_turn_seconds(episode_dir),
        })
    return rows


def main(argv: Optional[List[str]] = None) -> int:
    parser = argparse.ArgumentParser(description="Build the human episode table.")
    parser.add_argument("--results", default="results_human")
    parser.add_argument("--out", default=None)
    args = parser.parse_args(argv)

    results_root = Path(args.results)
    sessions_root = results_root / SESSIONS_DIRNAME
    rows = build_table(results_root, sessions_root)
    if not rows:
        print("no scored human episodes found")
        return 1
    out_path = Path(args.out) if args.out else sessions_root / "episodes.csv"
    out_path.parent.mkdir(parents=True, exist_ok=True)
    with out_path.open("w", newline="", encoding="utf-8") as handle:
        writer = csv.DictWriter(handle, fieldnames=list(rows[0]))
        writer.writeheader()
        writer.writerows(rows)
    print(f"wrote {len(rows)} rows to {out_path}")
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

````markdown
# humanweb

Humans play the covered matrix games through a browser. A participant is a
clemcore backend (`humanweb_api.py`), so episodes are structurally identical to
model episodes and `clem score` works unchanged.

Design: `docs/superpowers/specs/2026-09-01-human-matrixgame-web-design.md`

## Running an afternoon

Dry run first — shows what fits before your stop time:

```bash
python -m humanweb.console 6p --session aft03 --stop-in-minutes 240 --dry-run
```

Then for real, naming who sits where:

```bash
python -m humanweb.console 6p --session aft03 --stop-in-minutes 240 \
  --afternoon 3 --seats P01,P02,P03,P04,P05,P06 \
  --public-host 192.168.1.20
```

Hand each person their printed seat link. Ctrl-C stops for the day: the
in-flight episode writes no `interactions.json` and is replayed next time.

## After an afternoon

```bash
clem score -g matrixgame_covered_comm_6p -r results_human
python -m humanweb.join --results results_human
```

## Seat rotation

`humanweb.selection.seat_for(participant_index, afternoon_index, n_seats)` is a
cyclic Latin square. Pass `--seats` in that order each afternoon so every
participant visits every seat.

## What must never change

- No edits under `matrixgame_covered_*`, `matrixgame_covered_shared/`,
  `campaign/`, or `clemcore`. Enforced by `test_no_game_machinery_was_modified`.
- Never write `max_turns`. Human episodes use the canonical budget so their
  `instance.json` stays byte-identical to the model runs.
- All seats use the model name `human-text`, keeping one results tree per suite.
````
